## Featured projects

**[physics-sandbox](https://github.com/travisjones-dev/physics-sandbox)** · *C++20, CMake*\
A 2D physics engine I'm writing from scratch: fixed-timestep semi-implicit Euler integration, circle collisions with mass-weighted impulses, and tests that check physical laws (free fall, conservation of momentum). I broke the code on purpose to prove each test catches the bug. I benchmarked step time at 1,000–5,000 bodies (0.5–12.1 ms), which confirmed the O(n²) scaling of brute-force collision checks.

**[3d-cinematic-game](https://github.com/travisjones-dev/3d-cinematic-game)** · *Godot 4, GDScript*\
A story-first medieval fantasy RPG with a component-based interaction system, flag-driven quests and dialogue, cutscenes, save/load, and 70 automated regression tests.

**[frostfell](https://github.com/travisjones-dev/frostfell)** · *JavaScript, Three.js, GLSL*: **[▶ Play in your browser](https://travisjones-dev.github.io/frostfell/frostfell.html)**\

**[cat-platformer](https://github.com/travisjones-dev/cat-platformer)** · *Unity 6, C#*\
A 2D platformer built solo in an 8-hour game jam, with physics-driven toppling and door-unlock progression. I drew the cats.

**[adventure-game](https://github.com/travisjones-dev/adventure-game)** · *Python, Claude API*\
